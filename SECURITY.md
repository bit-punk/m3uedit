# Security Policy

## Supported versions

Security fixes are made for the latest [release](https://github.com/bit-punk/m3uedit/releases) only.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Report them privately using
[GitHub's private vulnerability reporting](https://github.com/bit-punk/m3uedit/security/advisories/new) instead.

Please describe the vulnerability, how it can be exploited and the version you found it in. You will get an answer
as soon as possible; once the vulnerability is fixed, it is published together with the release containing the fix.
